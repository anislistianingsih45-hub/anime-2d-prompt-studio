# Anime & 2D Animation Prompt Studio

A Claude Code plugin for creating structured anime, manga, and 2D animation prompts.

## Features

- Anime / manga image prompt builder
- 2D animation prompt builder with scene timing and camera continuity
- Character consistency checklist
- Style presets, including flat 2D and choppy stop-motion at 8 FPS
- English prompt output with optional Indonesian planning notes

## Install locally

Copy this repository into your Claude Code plugins directory, or test it as a local plugin using the current Claude Code plugin workflow.

> Plugin installation syntax and directory conventions can change. Check the current Claude Code documentation before installing.

## Example requests

- "Create an anime character prompt: a shy black cat wearing a red scarf, warm studio lighting."
- "Write a 9:16 flat 2D animation prompt: cat looks embarrassed for 3 seconds, sits at a piano for 0.5 seconds, then plays for 3 seconds. Side view, one continuous take, 8 FPS."
- "Turn this character description into a consistency sheet with front, side, three-quarter, and back views."

## Safety

This plugin is instruction-focused. It does not require API keys, network calls, shell scripts, or external dependencies for its core functionality. Review all files before installing and review any commands Claude proposes to run.
